# Skills

A collection of skill files that extend an AI assistant with focused, reusable capabilities. Each .skill file packages the instructions and workflow for a specific task so it can be loaded on demand.

## Available skills

### tailor-resume.skill (the most useful skill)

tailor-resume.skill is the standout skill in this repository. It helps you adapt a resume to a specific job by aligning your experience, wording, and highlighted accomplishments with the target role and its job description. Instead of manually rewriting your resume for every application, the skill guides the process of emphasizing the most relevant skills and keywords, tightening phrasing, and producing a version tuned to what a given employer is looking for.

Typical uses:
- Rewriting a general resume to match a specific job posting
- - Surfacing and emphasizing the experience most relevant to a role
  - - Aligning terminology and keywords with the job description
    - - Producing a cleaner, more targeted version for each application
     
      - ## Usage
     
      - Load the desired skill file into your assistant, then provide the required inputs (for example, your current resume and the target job description) to run the skill.
